# Smart Support System

A multi-domain AI-assisted support web app with the following domains:

- Hospital
- Education
- Work Profession
- Technical
- Bot (avatar-based conversational panel)

## Features

- Situation text box + **Analyse** action
- Domain-specific references and auto-search guidance
- Voice input via browser speech recognition
- Speak output via browser text-to-speech
- Camera/image input for Hospital and Technical domains
- Bot communication screen with animated avatar

## Run

Open `index.html` in a modern browser.

For local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
